<p>
    A first person survival horror game. The game will feature inventory management and story progression, and the gameplay loop will be heavily puzzle based. Pretty much go to one room, do a puzzle, go to the next, progress the story etc. The story of the game is not fleshed out yet, and im mostly focusing on the gameplay parts as of right now. <br><br>The game will eventually heavily feature a radio, which will be used to solve a majority of the puzzles. The style is aiming for retro futurism, although this might change.
</p>
<p>
    The game is made in Godot with GDScript and GDShader, and is inspired by games like Signalis. No AI was used in the development of this game.
</p>

<p>
    how to download:
</p>
<ol>
    <li>Navigate to the release section (https://github.com/Noah155433/movement-fps/releases)</li>
    <li>Select the appropriate version (most likely the newest)</li>
    <li>Download the zip associated with your OS (Windows or Linux)</li>
    <li>Unzip the folder</li>
</ol>
<p>
how to download (source):
</p>
<ol>
    <li>Press the big green download button</li>
    <li>Press download source</li>
    <li>Unzip the file</li>
    <li>In Godot, press the import button, navigate to the folder, and open the project.godot file</li>
</ol>

<p>
how to run:
</p>
<ul>
    <li>
    Windows:
        run "First person story game.console.exe" in the unzipped folder
    </li>
    <li>
        Linux:
        run "First person story game.(sh/x86_64)" in the unzipped folder
    </li>
</ul>

how to open (source):
<ul>
    <li>double press the imported project</li>
</ul>

Controls:
<ul>
    <li>wasd - movement</li>
    <li>mouse - camera</li>
    <li>lmb - shoot</li>
    <li>shift - sprint</li>
    <li>r - reload</li>
    <li>tab - inventory</li>
    <li>in inventory:
        <ul>
            <li>a and d - change slot</li>
            <li>e - interact with slot</li>
            <li>lmb - interact with buttons</li>
        </ul></li>
</ul>
