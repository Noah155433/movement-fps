A first person story/horror game with psx style graphics. 

The game is made in Godot with GDScript, and is inspired by games like Signalis. No AI was used in the development of this game.

how to download:
    Download the zip associated with your OS (Windows or Linux)
    Unzip the folder

how to run:
    run the exe in the unzipped folder

Controls:
    wasd - movement
    mouse - camera
    lmb - shoot
    shift - sprint
    r - reload
    tab - inventory
    in inventory:
        a and d - change slot
        e - interact with slot
        lmb - interact with buttons
