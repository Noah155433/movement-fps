A first person survival horror game. The game will feature inventory management and story progression, and the gameplay loop will be heavily puzzle based, e.g go to one room, do a puzzle, go to the next, progress the story etc. The story of the game is not fleshed out yet, and im mostly focusing on the gameplay parts as of right now. The game will eventually heavily feature a radio, which will be used to solve a majority of the puzzles. The style is aiming for retro futurism, although this might change.

The game is made in Godot with GDScript and GDShader, and is inspired by games like Signalis. No AI was used in the development of this game.

how to download:
    Navigate to the release section (https://github.com/Noah155433/movement-fps/releases)
    Select the appropriate version (most likely the newest)
    Download the zip associated with your OS (Windows or Linux)
    Unzip the folder

how to download (source):
    Press the big green download button
    Press download source
    Unzip the file
    In Godot, press the import button, navigate to the folder, and open the project.godot file

how to run:
    Windows:
        run "First person story game.console.exe" in the unzipped folder
    Linux:
        run "First person story game.(sh/x86_64)" in the unzipped folder

how to open (source):
    double press the imported project

Controls:
    wasd - movement
    mouse - camera
    lmb - shoot
    shift - sprint
    r - reload
    tab - inventory
    in inventory:
        a and d - change slot
        e - interact with slot
        lmb - interact with buttons
